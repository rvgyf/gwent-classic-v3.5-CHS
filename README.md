# 昆特牌经典版 v3.5

![封面](https://user-images.githubusercontent.com/26311830/116256903-f1599b00-a7b6-11eb-84a1-16dcb5c9bfc6.jpg)

本项目是基于 RandomPianist 的《昆特牌经典版》分叉版本修改而来。

这是一款在浏览器中重制的《巫师 3：狂猎》原版昆特牌小游戏，包含全部 DLC 卡牌。<br/>点击 [这里](https://randompianist.github.io/gwent-classic-v3.1/) 开始游玩。

除了克隆原版游戏之外，本项目还加入了大量新卡牌、新阵营、新技能和新功能，将游戏进一步发扬光大。

## 改进内容

此处仅列出当前这个分叉版本所做的修改，此前已有其他开发者完成过更多改进。

### 新增

- 网站图标（Favicon）
- 战绩统计表
- 「认输」按钮
- 轮播窗口的新视觉效果
- 更美观的警告提示样式

### 修复

- 拼写错误
- 无用代码
- 视觉参数
- 使用领袖牌时的 Bug
- 平局抽牌时的 Bug
- 每局开始时重抽卡牌时的 Bug

## 键盘操作说明

**"E"** 开始游戏<br />
**"X"** 使用或更换领袖牌<br />
**"Q"** 关闭卡牌说明窗口，或在游戏中认输<br />
**"空格"** 跳过本轮<br />
**"回车"** 打出卡牌<br />
**"方向键"** 在轮播窗口中选择卡牌
